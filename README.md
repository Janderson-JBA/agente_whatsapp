# Agente WhatsApp

Projeto simples para automatizar interações no WhatsApp usando Node.js.

## Objetivo

Este projeto cria um agente que pode responder mensagens automaticamente com base em regras e integração com modelos de IA.

## Requisitos

- Node.js
- npm

## Instalação

```bash
npm install
```

## Execução

```bash
node index.js
```
